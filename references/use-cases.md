# B-guru スキル ユースケース集

AI エージェント（Claude / ChatGPT / Hermes 等）から B-guru を使う具体例。
ツールはすべて MCP 経由または REST（`/api/agent/*`）で呼び出せます。

## 1. タイムライン要約レポート

**プロンプト例**: 「B-guru の今週のタイムラインを読んで、部活ごとの盛り上がりと主要トピックをまとめて」

**手順**:
1. `get_posts` を `since_id` ポーリングまたはページングで十分な件数取得（1 リクエスト 100 件上限・`cursor` で継続）
2. `get_clubs` で部活キー一覧を取得し、`club` フィルタで部活ごとに分類
3. 要約レポートを生成

**コツ**:
- 大量取得は `cursor` ページングを繰り返す（レート制限 read 120/min に注意）
- `since_id` を記録しておくと次回「その投稿以降の新着だけ」取得できる

## 2. 部活の盛り上がり分析

**プロンプト例**: 「AI 部の今月の投稿数とアクティブな投稿者トップ 5 を数えて」

**手順**:
1. `get_clubs` で AI 部のキーを確認
2. `get_posts` に `club` フィルタを付けてページング取得
3. 投稿数を日別に集計・投稿者別にカウント（`author_id` 単位・表示名は `author_name`）

## 3. キーワード横断スレッド収集

**プロンプト例**: 「『価格設定』についての過去の議論を全部拾って、論点を整理して」

**手順**:
1. `search_posts` に `q` を付けて検索（部分一致・ページング可）
2. ヒットした各投稿を `get_thread` で開いて返信ツリーごと取得
3. 議論の論点・結論・未決事項に整理

## 4. 自分の投稿ふりかえり

**プロンプト例**: 「俺の今月の投稿を全部拾って、振り返り記事の下書きを書いて」

**手順**:
1. `get_me` で自分の `user_id` を取得
2. `get_posts` に `author_user_id` を付けてページング取得
3. ブックマーク済みも `bm=1`（bookmark フィルタ）で取得し合わせて参照
4. ふりかえり記事のドラフトを生成

## 5. チャットの参加状況チェック

**プロンプト例**: 「チャットで最近何の話題が出てる？」

**手順**:
1. `get_chat` で履歴取得（24 時間以内・`before` でさらに過去へ）
2. 話題・参加者を要約

## 6. 新着通知の確認と対応

**プロンプト例**: 「未読の通知を確認して、返信が必要そうなものを挙げて」

**手順**:
1. `get_notifications` で通知取得
2. 返信が必要なものは対象投稿を `get_thread` で開き、`post_message` に `parent_id` を付けて返信ドラフトを作成（**自動投稿する前に必ずユーザーに確認**）

## 注意事項

- **投稿・返信はユーザーの確認を得てから**: エージェントが勝手に投稿しない。ドラフト提示 → 確認 → `post_message` の順で
- 書き込みは 10 回/時のレート制限。連投は避ける
- `membership_ended` が返ったら会員資格の問題なのでユーザーに伝える
